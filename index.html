📖 使用指南

三步搞定教学准备，从想法到可直接进教室的方案：

1
选工具
在左侧「工具索引」里按分类（课前备课 / 阅读教学 / 写作教学 …）点开折叠列表，挑一个适合当前任务的工具。
2
填内容
在弹出的窗口中按提示粘贴课文、题目、作文或语篇文本，按需补充年级 / 水平等字段，越具体产出越贴合。
3
点运行
点击「▶ 运行工具」，AI 一键生成结构化教学方案；可复制、可继续追问调整。

提示：首次使用请先点击右上角 ⚙️ 配置 API（本地代理或云端安全代理），否则为演示模式。

☁️ 想在云端链接上独立运行 AI（无需本机服务器、且 Key 不暴露）？

推荐：勾选「☁️ 云端安全代理」，把 server.js 部署到 Render/Vercel，Key 存进平台环境变量，浏览器只发提问。适合公开分享。

备选（仅个人自用）：关闭「本地代理」，选用支持浏览器直连的服务商：

• 🌐 OpenRouter：OpenAI 兼容 + 支持浏览器 CORS，一个 Key 可用几百种模型（含免费 Gemini）

• ✨ Google Gemini：免费额度大、原生支持 CORS

⚠️ 浏览器直连会把 API Key 暴露在前端，仅建议个人自用；公开分享前请改用「云端安全代理」。

支持的 OpenAI 兼容服务商：

• 商汤 Token(开放平台)：https://token.sensenova.cn/v1 / 模型 sensenova-6.7-flash-lite（Key 来自 platform.sensenova.cn）

• DeepSeek：https://api.deepseek.com/v1 / 模型 deepseek-chat

• OpenAI：https://api.openai.com/v1 / 模型 gpt-4o

• Moonshot：https://api.moonshot.cn/v1 / 模型 moonshot-v1-8k

• 通义千问：https://dashscope.aliyuncs.com/compatible-mode/v1 / 模型 qwen-plus

• 智谱 GLM：https://open.bigmodel.cn/api/paas/v4 / 模型 glm-4-flash

⚠️ 商汤两套系统 Key 不互通：在大装置注册的 Key 只能用 compatible-mode 端点；在开放平台注册的 Key 只能用 token 端点。选错会报 401 鉴权失败。

⚠️ 商汤 Token 等端点不在 CORS 预检里放行 Authorization 头，浏览器无法直连。纯静态云端站点必须配合「云端安全代理」（部署 server.js）或本地代理才能调用商汤。

Key 仅存储在浏览器 localStorage 中，经本地代理转发，不经过任何第三方服务器。
